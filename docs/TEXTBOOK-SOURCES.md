# Источники ответов и оценка релевантности

## Источники

Текущая рабочая библиотека:

- **Учебник 1 / Уч.1** — протоиерей Геннадий Нефёдов, «Таинства и обряды Православной Церкви».
- **Учебник 2 / Уч.2** — протоиерей Николай Сильченков, «Практическое руководство при совершении приходских треб».

Для текущих двух учебников по каждой из 171 нормализованной темы хранится независимый ответ.

Архитектура не требует, чтобы каждый будущий источник имел ответ на все 171 темы. Новый источник индексируется и сопоставляется только с теми темами, которые он действительно раскрывает. После анализа источник может выполнять роль основного учебного, справочного, тематического или дополнительного богословского / исторического материала.

## Шкала rel

Оценка `rel_1…rel_5` показывает не литературное качество ответа, а **релевантность материала конкретного учебника поставленному вопросу**.

- **rel_5** — учебник прямо и практически полностью отвечает на вопрос.
- **rel_4** — прямой материал есть, ответ в основном полный, но чего-то не хватает.
- **rel_3** — учебник даёт существенную часть ответа, но вопрос раскрывается лишь частично.
- **rel_2** — имеются только отдельные сведения, относящиеся к вопросу.
- **rel_1** — прямого материала практически нет.

Правила представления:

- при `rel_2` в ответ включаются только сами полезные сведения из источника. Метатекст типа «в учебнике имеются только отдельные сведения», «учебник не даёт полного ответа» и сходные формулы не используется;
- при `rel_1` ответ не достраивается общими знаниями: допустима краткая констатация «Прямого ответа в этом источнике нет.»;
- содержание любого ответа должно оставаться прослеживаемым к конкретному источнику.

## Статус оценок

Первичная раскладка `rel` и первичное сопоставление Учебника 2 выполняются автоматически по заголовкам, тексту разделов и типу вопроса. Метод помечается как `automatic_initial_v1`.

Это **не окончательная содержательная аттестация**. Оценки и ответы должны последовательно проверяться вручную по мере работы с экзаменационными вопросами. Ручная проверка имеет приоритет над автоматической оценкой.
