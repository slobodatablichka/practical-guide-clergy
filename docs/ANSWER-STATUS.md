# Статус кратких ответов

- Нормализованных тем: **171**.
- Сформировано кратких ответов: **171**.
- Пустых ответов: **0**.
- Основной источник: EPUB `Таинства и обряды Православной Церкви`.
- Ответы формируются только из текста учебника; внешние источники на этом этапе не используются.
- Для структурных заголовков без собственного текста используются явно связанные подразделы учебника.
- Несколько ответов с повышенным риском неоднозначности вручную уточнены по тексту соответствующего раздела.

`data/answers.json` является рабочим слоем кратких ответов сайта. Исходные формулировки экзаменационных билетов хранятся отдельно в `source/tickets-original.txt` и `data/ticket-questions.json` и при формировании ответов не подменяются.
