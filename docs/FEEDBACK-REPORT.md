# Отчёт по пользовательским оценкам

## Назначение

`scripts/build_feedback_report.py` превращает CSV, выгруженный из Supabase-представления
`public.feedback_analysis`, в один автономный HTML-файл с диаграммами и предварительным анализом.

Отчёт предназначен для локального просмотра владельцем проекта. Он может содержать имена/псевдонимы
и комментарии посетителей, поэтому его нельзя автоматически публиковать в публичном GitHub-репозитории.

## Локальные файлы

Рекомендуемая структура:

```text
C:\Projects\Practical-Guide-Clergy\feedback\
    feedback-analysis.csv
    feedback-report.html
```

CSV и HTML из каталога `feedback/` исключены из Git.

## Построение отчёта

Из корня проекта:

```powershell
py .\scripts\build_feedback_report.py .\feedback\feedback-analysis.csv
```

По умолчанию программа создаёт:

```text
feedback\feedback-report.html
```

Открыть его можно двойным щелчком в Edge/Chrome. Интернет для просмотра отчёта не нужен.

Можно явно задать имя результата:

```powershell
py .\scripts\build_feedback_report.py .\feedback\feedback-analysis.csv -o .\feedback\report-2026-09-24.html
```

## Состав отчёта

- число отзывов;
- приблизительное число участников по имени/псевдониму;
- число оценённых вопросов;
- средняя оценка;
- доля отзывов с комментариями;
- число оценок 1–2;
- диаграмма распределения оценок;
- сравнение средней оценки Уч.1 и Уч.2;
- матрица `rel × пользовательская оценка`;
- вопросы с наибольшим числом отзывов;
- ответы с наиболее низкой средней оценкой;
- сигналы «высокий rel / низкая оценка»;
- сигналы «низкий rel / высокая оценка»;
- комментарии;
- полная исходная таблица с локальным поисковым фильтром.

## Ограничение предварительного анализа

Программа выполняет только воспроизводимый числовой и правиловой анализ. Она не делает смысловой
ИИ-анализ текста комментариев. Для содержательной группировки замечаний CSV или HTML-отчёт можно
передать ChatGPT отдельно.
