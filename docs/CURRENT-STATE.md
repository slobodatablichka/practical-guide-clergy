## Текущий статус качества

Первичная разметка `rel` и первичное сопоставление Уч.2 построены автоматически по структуре и тексту EPUB. Они являются **рабочей первичной оценкой**, а не окончательной содержательной аттестацией.

На этапе автоматической проверки отдельно исправлены особенности структуры Сильченкова: повторяющиеся рубрики «Обрядовый порядок», «Время и место», «Церковные правила» привязаны к конкретной требе; пустые рубричные страницы не принимаются за источник.

## Система отзывов

Архитектура пользовательской оценки утверждена и подключена к Supabase-проекту `practical-guide-clergy` (`eu-north-1`, Free).

- отзыв относится к паре `topic_id + book_id`;
- пользовательская оценка 1–5 оценивает качество конкретного ответа и не смешивается с `rel_1…rel_5`;
- имя обязательно при первом использовании и затем хранится в браузере;
- комментарий необязателен;
- одна актуальная запись на пользователя, вопрос и учебник; повторная оценка обновляет её;
- в записи должны сохраняться версия ответа, контекст показа и временные метки;
- хранилище — PostgreSQL/Supabase, таблица `answer_feedback`;
- анонимная авторизация включена; техническая сессия создаётся только при первой реальной оценке;
- RLS разрешает пользователю читать и изменять только собственные отзывы;
- допустимы только 171 каноническая тема и два зарегистрированных учебника;
- комментарий ограничен 2000 знаками;
- форма оценивания встроена в открытый ответ в билетах, «По учебнику» и поиске;
- Security Advisor после включения anonymous sign-ins показывает только ожидаемое предупреждение о том, что анонимные пользователи имеют собственные RLS-права на `answer_feedback`; это соответствует принятой модели;
- Performance Advisor не выявляет проблемы схемы; новый индекс по `topic_id` до появления трафика может отмечаться как ещё не использованный;
- создано представление `public.feedback_analysis` для удобного просмотра/CSV-экспорта отзывов;
- создан локальный генератор `scripts/build_feedback_report.py`: CSV → автономный HTML-отчёт с диаграммами и предварительным анализом;
- локальные файлы `feedback/*.csv` и `feedback/*.html` исключены из публичного Git-репозитория.
