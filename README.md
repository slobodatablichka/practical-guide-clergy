# Практическое руководство для священнослужителя

Учебный справочник для подготовки к зачёту.

- 30 билетов × 6 вопросов = 180 экзаменационных позиций.
- 171 нормализованная учебная тема.
- Краткие ответы подготовлены по учебнику прот. Геннадия Нефёдова «Таинства и обряды Православной Церкви».
- Навигация: по билетам, по порядку учебника, поиск.
- Каждая тема содержит переход к соответствующему разделу встроенного учебника.

## Книга

EPUB хранится без изменения содержимого в `assets/book/chunks/` как base64-части из-за способа автоматической загрузки проекта. Контрольная сумма и порядок частей находятся в `assets/book/manifest.json`. Для восстановления исходного `.epub` после клонирования:

```powershell
py scripts/reconstruct_book.py
```

## Источники

- `source/tickets-original.txt` — исходный перечень билетов;
- `data/` — нормализованный реестр, ответы и индекс учебника;
- `docs/` — контрольные документы проекта.

Сайт предназначен для публикации через GitHub Pages из ветки `main`, корень репозитория.
