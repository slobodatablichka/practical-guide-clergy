# Практическое руководство для священнослужителя

Справочно-учебная система, созданная в рамках изучения курса БПДС «Практическое руководство для священнослужителя».

Главный объект проекта — экзаменационный вопрос / нормализованная тема. Учебные и справочные книги подключаются как независимые источники материала; проект не ограничен двумя текущими учебниками.

## Состав проекта

- 30 билетов × 6 вопросов = **180 экзаменационных позиций**;
- **171 нормализованная тема**;
- два подключённых независимых учебника-источника с архитектурой дальнейшего расширения библиотеки;
- по каждой теме хранится отдельный ответ и оценка релевантности `rel_1…rel_5` для каждого учебника;
- исходные формулировки билетов сохраняются без подмены нормализованными;
- в билете одновременно открыт только один ответ — после выбора **Уч.1** или **Уч.2**;
- навигация сайта: **Билеты / По учебнику / Поиск**.

## Учебники

1. **Уч.1** — протоиерей Геннадий Нефёдов, «Таинства и обряды Православной Церкви»:
   `assets/book/taintstva-i-obryady-pravoslavnoy-tserkvi.epub`.
2. **Уч.2** — протоиерей Николай Сильченков, «Практическое руководство при совершении приходских треб»:
   `assets/book/silchenkov-prakticheskoe-rukovodstvo-pri-sovershenii-prikhodskikh-treb.epub`.

## Основные данные

- `source/tickets-original.txt` — исходный список билетов;
- `data/ticket-questions.json` — 180 экзаменационных позиций;
- `data/topics.json` — 171 нормализованная тема;
- `data/textbooks.json` — реестр учебников;
- `data/textbooks/nefedov/` — индекс и ответы Уч.1;
- `data/textbooks/silchenkov/` — индекс и ответы Уч.2;
- `data/relevance-status.json` — сводка оценок релевантности;
- `docs/TEXTBOOK-SOURCES.md` — методика `rel`.

Первичные автоматические оценки и сопоставления являются рабочей разметкой и подлежат последовательной ручной содержательной проверке.

## Сайт

- `index.html` — основной интерфейс;
- `reader.html` — встроенный просмотр выбранного EPUB;
- `assets/app.js` — билеты, два источника, порядок по учебнику и поиск;
- `assets/styles.css` — оформление.

Проект публикуется через GitHub Pages из ветки `main`.


## Отчёты по отзывам

- `scripts/build_feedback_report.py` — локальный генератор красивого автономного HTML-отчёта из CSV Supabase;
- `docs/FEEDBACK-REPORT.md` — инструкция;
- локальные CSV и HTML хранятся в `feedback/` и не публикуются в Git.


## Стратегическое развитие

Принята модель масштабирования до шести и более источников. В план расширения библиотеки внесены:

- Булгаков С.В. «Настольная книга для священно-церковно-служителей»;
- Дебольский Г.С., прот. «Православная Церковь в ее Таинствах, богослужении, Обрядах и Требах»;
- Остапов А.Д., прот. «Пастырская эстетика»;
- Кураев А., диак. «Традиция, Догмат, Обряд : апологетические очерки».

Новый источник не обязан покрывать все 171 темы. Его фактическая роль и охват определяются после анализа содержания.

Стратегическая модель проекта закреплена в `docs/PROJECT-CONCEPT.md`.
