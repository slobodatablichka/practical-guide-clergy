# Практическое руководство для священнослужителя

Учебный справочник для подготовки к зачёту по предмету «Практическое руководство для священнослужителя».

## Состав проекта

- 30 билетов × 6 вопросов = **180 экзаменационных позиций**;
- **171 нормализованная тема**;
- **171 краткий ответ**, сформированный по учебнику;
- исходные формулировки билетов сохранены отдельно и не подменяются нормализованными;
- навигация сайта: **Билеты / По учебнику / Поиск**;
- каждый ответ связан с одним или несколькими разделами учебника;
- учебник хранится в репозитории как канонический EPUB:
  `assets/book/taintstva-i-obryady-pravoslavnoy-tserkvi.epub`.

## Основные данные

- `source/tickets-original.txt` — исходный список билетов;
- `data/ticket-questions.json` — 180 экзаменационных позиций;
- `data/topics.json` — 171 нормализованная тема;
- `data/answers.json` — краткие ответы;
- `data/book-index.json` — структурный индекс учебника;
- `docs/QUESTION-REGISTER.md` — читаемый реестр вопросов;
- `docs/MAPPING-REVIEW.md` — неоднозначные сопоставления, требующие особого контроля.

## Сайт

- `index.html` — основной интерфейс;
- `reader.html` — встроенный просмотр EPUB;
- `assets/app.js` — билеты, порядок по учебнику и поиск;
- `assets/styles.css` — оформление.

Проект предназначен для публикации через GitHub Pages из ветки `main`, корень репозитория.
